## Why M2 (the A2 baseline R is not reused)

The A2 baseline (`p037-a2-baseline-*.json`, R = `5fd6bfa`) was taken in
operator environment `P037_A2_MEASUREMENT_M1`, which is not reachable from
here. This container matches M1 on .NET SDK 8.0.425 (runtimes 8.0.31) and
rustc/cargo 1.94.1. Its CPython 3.11.15 build string differs, though
(`GCC 13.3.0` here, `GCC 16.1.1` in M1). The harness enforces the
separation. `p037_mos_snapshot.py compare` between R and an M2 take answers
`REFUSED: before/after execution profiles differ`. Both sides of the
differential below were therefore taken in M2, and both are committed.
